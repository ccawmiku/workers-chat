## 缓存与可靠性优化（本轮）

- 公共 U/S 与最近真实 UA 提前到插件独立参考之前；摘要和历史参考使用稳定位置，复制分支不因内部随机 ID 打断前缀。对象分析与澄清对齐 JSON 对象模式，自定义非对象 Schema 保持。
- 新主回复保存实际工具轨迹并在后续请求原位置恢复，普通导出/前置 UA 排除；同轮反复问冻结基础资料。重写的固定约束放原句前，候选窗口共用同一对调历史。
- 前端优先显示上游比例，其次由返回用量计算，最后可显示明确标注的本地前缀估算。深蓝未缓存输入、浅蓝缓存，缓存不重复计总量。无额外统计接口/轮询/预热请求。
- 摘要未独立配置时跟随当前主模型；共享备用列表支持全部插件/摘要失败后的手动单次切换，后续操作回原配置。
- 明确继续澄清必须生成新题，默认推荐 A–D；空/重复结果报错保留回答，不自动循环。跳过与选项统一选中样式，结束按钮使用主题色。
- 上下文卡可折叠为细条，取消聊天顶栏，用角落按钮保留导航和设置；功能图标统一维护，主回复/摘要/局部生成图标区分。
- DeepSeek 工具/思考请求 400 已直接复现并确认 reasoning_content 要求；保存的真实思考原样传递，人工工具调用标记空字符串，不降强度。
- 插件/摘要 POST 可直接带回状态，前端采用快照，减少随后的 GET 聊天与导航；保留设备任务只交付一次及已有推送。
