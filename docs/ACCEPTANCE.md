# 验收检查

以用户最新确认、AGENTS.md、SPEC.md 和 PLUGINS.md 为准。已执行的具体检查记录在 PRODUCTION.md，以下是后续维护的回归范围，不把所有条目自动视为已通过。

## 聊天、数据与访问控制

- 登录/退出/会话撤销、同源保护、连续失败限制与提醒；密钥普通接口不返回。
- 消息树、user编辑分支、assistant覆盖、重新生成问答组、继续/停止/版本切换；Fork数字编号与位置正确。
- 导入导出往返，插件/摘要不混入主assistant正文或普通导出；完整树与单分支区别明确。
- 真实内容变化保存，重复已读/相同配置不写整份快照；并发更新不覆盖新版本。
- 关闭页面超过30秒的服务端生成仍完整落库，流式断连不重复上游请求。

## 插件与摘要

- 前置固定澄清→写前分析；独立模型/温度/思考强度/stream/system；默认inherit，错误不静默降级。
- 问题JSON校验、选项自由组合、自由回答、未选题跳过；首批2–4题，不合格不放行；反复问含完整已提交问答且限定原提示范围，明确继续空/重复批次可恢复报错，结束操作提交当前内容。
- 写前分析分块，非主角内心、已有状态与none；独立生成不改其他块；局部失败/取消保留原文，原结果变化后候选不能覆盖。
- 类型仅本轮/保存到当前对话/明确全局，持续类型后续每轮自动生成，结果旁可停用后续生成；全量重生成回初始请求。已完成历史只读，未确认候选刷新清理且无新模型请求，并发确认受保护。
- 临时输入和主草稿互不污染，动态插件名称，取消恢复草稿，块内手动编辑；缓存率上游值优先、计数本机计算、本地前缀估算注明来源；未知不伪装0。
- 摘要源版本失效、历史缺失前300 Unicode字符兜底、首份采用/重生成确认、旧数据串行补齐；100–150目标不机械截断。

## 布局与性能

- Chromium/WebKit桌面与手机：问题卡横排/纵排、侧栏底部上下排列、固定保存区、无横向溢出、键盘/触屏/焦点正常。
- 暗浅主题、强调色与圆形色板、提示对比度、紧凑卡片和深蓝输入/浅蓝缓存/黄思考/粉输出；Token单位和缓存百分比正确。
- 上滑暂停跟随、主动回底恢复，流式结束状态与完整正文一致。
- 一次bootstrap、空闲导航每分钟一次、隐藏停刷、生成推送不轮询；额度复用原请求和短缓存，无额外DO/D1缓存写入。
- 账号级Workers/DO/D1/Workflows额度范围、未知值、UTC日重置、CPU单次限制、容量峰值区分正确。
