## 本轮修复

1. **导入部分写入后报错**：原先逐个保存却在单次请求中超过免费查询预算，失败时不返回已导入 ID。现先规划原子批次，超限前拒绝；界面每次处理一项，保留成功结果并列出失败项，禁用重复确认，不自动重试结果未知的写入。
2. **消息树原型引用**：`__proto__`、`constructor`、`toString` 和空字符串能被当成父消息/节点。现只查自有属性，非法引用在导入与操作入口被拒绝。
3. **GET 可改变状态**：停止、已读和退出等入口原先没有严格限制方法。现集中声明允许的方法，拒绝错误方法；正常写入继续要求同源 JSON。
4. **流式解析边界**：修复 CRLF 跨数据块、UTF-8 分割和 DONE 后连接保持打开造成的等待；保留 DONE 前 usage，限制完整事件大小。
5. **停止后正文仍挂起**：DO 中保存当前 AbortController，取消同时中止请求与正文读取；取消与异常竞态保存为 stopped，释放运行中的协调器，不覆盖成 error。
6. **草稿覆盖**：旧保存请求可能晚于发送到达，新输入又会被发送成功后的清空覆盖。现串行化保存，提交时等候旧保存、暂缓自动保存，再保存较新的输入；首次输入也会建立聊天保存草稿。
7. **请求预览副作用与轮数差异**：预览不再写云端草稿；待发送用户消息计入轮数限制，预览与实际发送使用相同预算。
8. **密钥窗口晚响应**：关闭会使旧验证请求失效，晚到结果不进入可再次显示的状态；重新打开需要再次验证。
9. **任务/正文读取竞态**：分别读取聊天版本和任务状态，可能返回旧 running 正文及空任务。现同一 SQL 快照读取版本与活动任务，再读取该不可变版本。
10. **配置和界面容错**：无有效默认模型返回明确 400，按钮与 Enter 均不提交；损坏的设备外观配置回退默认值；Top K 输入范围保持一致。

## 实测边界

- 新回归只使用 mock 上游或浏览器拦截，不重复已完成的真实模型请求，不产生真实模型费用。
- 中止测试确认本地协调器结束读取并保存 stopped，不能保证远端供应商立即停止计算或停止计费。
- 保留 Cloudflare Free 能力范围，不执行生产部署；不存在“测试通过等于线上配额已验证”的结论。
- 安全响应头已存在于 `public/_headers` 与 API 响应；已按官方静态资源 headers 文档核对，本轮不声称新增此前已有的保护。
