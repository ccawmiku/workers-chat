# 上线后的界面调整

依据用户 2026-10-16 提供的新截图与明确要求，更新现有 React + TypeScript 前端；没有迁入外部应用的私有源码或重写聊天存储。

## 最终行为

- 设置弹窗桌面最大 1680px、宽度受 94vw 约束、高度约 92dvh；手机全屏，内容独立滚动。
- 左下角统一为头像账户入口，展开后选择设置、外观、账号与设备、导入、归档、回收站、多选和退出。桌面和手机使用同一菜单。
- 删除输入框下的固定免责声明及常驻估算行，超预算时仍保留必要提示。
- 上下文圆环可悬停或点击，弹层展示背景信息窗口、已用/剩余百分比、已用标记及总预算，明确为本地估算。
- 思考强度改为自定义 Codex 风格弹层：顶部图标、当前中文档位、重置、模型入口，以及粉色轨道、分档点、白色圆形滑块。默认最高 max；无发送 none，跟随接口省略字段。键盘方向键、Home/End 和重置均可用。
- 消息三点菜单移除，复制 Markdown、编辑、重生、Fork、续写、错误重试、上下文开关、复制纯文字及详情分别直接显示图标。用户消息操作移至气泡下方；历史用量仍可悬停、聚焦或手机长按查看。
- 移除消息及后续分支删除的前端入口和 API。完整聊天回收站保留。
- 上下文开关以用户问题和全部回复版本为一组，从问题或回复操作一致；后续轮次、编辑后的其他用户分支保持独立。发送、预览和圆环估算遵循同一规则，兼容历史半组排除标记。
- 聊天管理并入右侧当前聊天设置，保留重命名、标题生成、置顶、归档、移动、导入导出和会话回收站；取消独立页头三点管理入口。

## 验证

- 类型检查、32 项单元/workerd 集成测试和生产构建通过。
- 9 项 Chromium/WebKit 浏览器用例通过。新增两项覆盖桌面/手机头像、放大的设置、整轮上下文、无删除入口、用量弹层、六档强度键盘切换及重置；补查 320px 窄屏、844×390 横屏及 390×360 矮屏弹层边界。
- 浏览器测试只使用本地构造数据与 mock，不替换生产设置、不提交真实模型请求。
- 配置衔接修复：`database.config.ts` 为生产绑定及本地初始化共用数据库身份，仍使用本地模拟状态，不向远端运行开发初始化。
- 本地失败快照曾包含测试密码，已清理并轮换本地测试密码；登录提交结束会清空密码输入，避免失败页长期留存输入值。
