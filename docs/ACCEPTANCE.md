# 验收标准

对应需求以 `SPEC.md` 为准。本轮已继续实现标题、设置备份与管理交互；实际通过的命令、30 项 TypeScript 测试、2 项离线 Python 测试、7 项浏览器用例、截图和剩余项见 [PROGRESS.md](PROGRESS.md)。下列复合验收项尚未全部逐条完成，因此保留未勾选状态，不把局部测试或文档存在当作整个需求通过。

## 1. 产品与 UI

- [ ] 桌面浅/暗色和手机主要布局按参考图核对；无附件/语音/权限入口。
- [ ] 输入框、模型搜索菜单、思考强度菜单、上下文圆环；默认 max，none 与省略字段可区分。
- [ ] 温度/Top P/Top K 默认不发；右侧模板卡片、多选排序、替换/追加开关和标题范围开关。
- [ ] 左侧单层分组、组内置顶、按活动排序、归档、回收站和批量操作。
- [ ] 转圈、红圈感叹号、完成未读粉点；打开会话清除完成粉点。
- [ ] 手机长按菜单、版本列表、参数面板；外观和打开位置按设备记录。

## 2. 模型身份与请求

- [x] 两个提供商均有同名模型时，不错误合并或发给另一个服务商。
- [x] 可选前缀只影响显示，实际发送原始 model ID。
- [ ] 新模型默认关闭；刷新保留开关与上下文容量配置；支持批量开关及搜索。
- [ ] 关闭只隐藏菜单，已选/默认/历史模型仍可调用；真正缺失模型切默认，默认也缺失时提示且不能发。
- [x] 不支持参数的上游错误明确显示；不静默去参/降档/改协议。
- [ ] 超出应用配置容量仅提示；手动轮数限制、排除消息和系统模板影响实际上下文及圆环估算。
- [ ] 历史思考内容保存展示，但不重发给模型；用量区分实际和估算。

## 3. 消息树与 OpenWebUI 兼容

- [x] 用户编辑、AI 重生、失败重试形成可切换版本；AI 手动编辑原位覆盖。
- [x] 续写保留原版本，新版本包含旧正文＋追加正文。
- [ ] 树状总览能切换正确路线；同一消息排除对所有关联分支生效。
- [ ] 用户/AI 节点均可 Fork，复制正确祖先路线、设置和分组，无草稿复制。
- [x] Fork 标题分支A/B递增，反复 Fork 不堆叠后缀。
- [ ] 删除消息/子树显示影响且仅删指定子树；会话回收站与消息永久删除区别明确。
- [ ] 使用选定 OpenWebUI 稳定版的实际格式构造多分支测试：导入→编辑/重生/Fork→导出，树、路线、时间、正文和应保留元数据一致。
- [ ] 附件删除而文字保留，正文图片只保留文字/链接、不远程加载。
- [ ] 重复导入新增独立聊天；单项坏数据不阻塞整批；导入预览数量准确。
- [ ] JSON 保存完整树、Markdown 仅当前路线；正常/归档和回收站导出范围正确。

## 4. 生成、断线与状态

- [ ] 同一聊天生成时不能再次发送或编辑历史，草稿不自动提交；不同聊天可生成。
- [ ] 切模型只影响后续请求；流式开关均能正常保存、停止及展示错误。
- [ ] 停止保留半截，默认纳入上下文且可切换；真实报错保留半截并可新版本重试。
- [ ] 浏览器刷新/切页/断开后重新打开，不重复提交同一次模型请求。
- [ ] 完整关闭页面超过 30 秒后，既有回答继续完成并保存；真实免费环境结果与本地模拟区分。
- [ ] 后台中断、额度耗尽、上游超时可恢复并明确失败状态，不以无限重试制造多次调用。
- [ ] 长对话/大树/接近配置预算的文本不破坏 Unicode、不被数据库单值限制截断。

## 5. 登录、安全与备份

- [ ] HTTPS/WSS，外部上游 HTTPS，不关闭 TLS 验证、不带密钥跟随不可信重定向。
- [ ] 未登录不能读聊天/密钥/设置；会话 Cookie、跨站请求防护和登录限速有效。
- [ ] 修改密码、离线恢复码重置、退出设备均能使对应会话失效；恢复码不以明文校验值保存。
- [ ] 查看 API Key 必须重新验证密码；普通接口和错误不泄露密钥。
- [ ] 日志/测试报告/仓库无真实密钥、密码、恢复码或正文日志。
- [x] 设置备份默认不包含密钥；主动包含时明确提示且为用户选定的普通 JSON。
- [x] 设置恢复支持合并/替换，聊天 JSON 导入仍新增；登录凭证不通过普通聊天备份迁移。
- [ ] 云端草稿按最后写入覆盖；不额外实现全设备即时同步。

## 6. 交付

- [ ] 应用代码、依赖锁文件、数据库迁移、可复现的运行/检查/构建命令。
- [ ] 有意义的单测、Worker 集成验证、桌面与手机浏览器截图。
- [ ] mock 结果、真实 API 结果和真实免费 Cloudflare 结果分别说明。
- [ ] README、部署/恢复步骤、运行时/许可参考及剩余限制。
- [ ] PR 可以独立审阅，未使用任何付费 Cloudflare 功能。

## 7. 标题任务

- [x] 首次回答仅自动生成一次；失败不覆盖回答、不自动重发同一任务。
- [x] 支持独立模型/提示词；默认模型后备只尝试一次且不重复同一模型。
- [x] 手动生成支持首轮/当前分支材料，不发送历史思考；手动改名不被旧任务覆盖。
- [ ] 实际上游和真实免费账户中的标题超时/重启/配额故障验证。

最新按规格核验及已确认限制见 [完成度审计](REVIEW-2026-10-16.md)。原有复合项不会因新增局部回归而全部勾选。
